📋 PC Shift Table — User Guide

คู่มือการใช้งานระบบจัดตารางกะ และติดตาม Performance

ภาพรวม เลือกประเทศ ตารางกะ Keyboard Shortcuts ตั้งค่า Promoter ตั้งค่าร้าน Sales Performance Auto Assign Attendance Database Export ข้อมูล LINE Attendance

🏠 ภาพรวมระบบ

PC Shift Table เป็นระบบจัดตารางกะสำหรับ Promoter ในร้านค้า รองรับทั้ง UAE 🇦🇪 และ Qatar 🇶🇦

ระบบประกอบด้วย 6 หน้าหลัก:

Tabหน้าที่
Shift Tableจัดตารางกะ — เลือกร้าน, เวลา, ใส่โน้ต
PC Settingจัดการ Promoter — ชื่อ, วันหยุด, ร้านที่ชอบ/ห้าม

📅 ตารางกะ (Shift Table)

การใส่กะ

  1. คลิกที่ช่อง ในตาราง (แถว = Promoter, คอลัมน์ = วันที่)
  2. เลือก ร้าน จาก dropdown — พิมพ์ชื่อร้านเพื่อค้นหาได้
  3. ถ้าร้านมีหลาย Shift Slot จะขึ้นให้เลือก ช่วงเวลา (เช่น 10:00-19:00 หรือ 13:30-22:30)
  4. กดเลือก — กะจะถูกบันทึกอัตโนมัติ

กะพิเศษ

รหัสความหมาย
Offวันหยุด
LOPขาดงาน (Leave of Presence)
SLลาป่วย (Sick Leave)
ALลาพักร้อน (Annual Leave)
—ยังไม่จัดกะ (คลิก "-" เพื่อลบกะ)

ใส่โน้ต

ดับเบิลคลิก ที่ช่องกะ เพื่อเปิดช่องใส่โน้ต

  • กด Enter เพื่อบันทึก
  • กด Escape เพื่อยกเลิก
  • กด Shift+Enter เพื่อขึ้นบรรทัดใหม่

Special Date (มาร์ควันพิเศษ)

คลิกที่ หัวคอลัมน์วันที่ เพื่อมาร์ควันพิเศษ:

  • 🔴 Holiday — วันหยุดนักขัตฤกษ์
  • 🟡 Event — อีเว้นต์พิเศษ
  • 🟣 Promo — โปรโมชั่น
  • 🔵 Note — โน้ตทั่วไป
  • 🟢 Payday — วันเงินเดือนออก

Filter Panel (แถบกรอง)

กดปุ่ม Filter ที่ด้านบนเพื่อเปิด/ปิด Filter Panel:

  • ช่วงวันที่ — เลือก Start/End date
  • ซ่อน/แสดงร้าน — เลือกร้านที่ต้องการแสดง
  • ซ่อน/แสดง Promoter — เลือก Promoter ที่ต้องการแสดง
  • Active Promoters Only — แสดงเฉพาะ Promoter ที่ active
  • Hide Empty Stores — ซ่อนร้านที่ไม่มีคนจัดกะ

⌨️ Keyboard Shortcuts

เลื่อนเมาส์ไปที่ช่องกะจะเห็น กรอบสีฟ้า — แปลว่า focus อยู่ที่ช่องนั้น

ปุ่มการทำงาน
↑ ↓ ← →เลื่อน focus ไปช่องข้างเคียง

⌘+VPaste กะที่ copy ไว้ลงช่องที่ focus
⌘+ZUndo (เลิกทำ) — ย้อนได้ถึง 50 ครั้ง
⌘+⇧+ZRedo (ทำซ้ำ)

📊 Sales Performance

Performance Index (PI)

คำนวณจากยอดขายเฉลี่ยต่อวันของ Promoter เทียบกับค่าเฉลี่ยของร้าน:

PI = ยอดขาย Promoter ÷ ค่าเฉลี่ยร้าน (ถ่วงน้ำหนักตามจำนวนวันที่ทำ)

เกรดPIความหมาย
A≥ 1.15สูงกว่าค่าเฉลี่ย 15%+
B≥ 0.95ใกล้เคียงค่าเฉลี่ย
C≥ 0.75ต่ำกว่าค่าเฉลี่ย
D< 0.75ต่ำกว่าค่าเฉลี่ยมาก

Store Tier

คลิกที่ร้านในรายการ Store Tiers เพื่อกำหนด Tier (A → B → C → D → ลบ)

หรือกด Auto-calculate from Revenue เพื่อคำนวณจากยอดขายอัตโนมัติ

ร้านที่ inactive จะแสดงเป็นสีเทาจาง แต่ยังกำหนด Tier ได้หากมี Order data

Grade-to-Tier Matching (FitMap)

กำหนดว่า Promoter เกรดไหนเหมาะกับร้าน Tier ไหน:

เกรด PromoterTier ร้านที่เหมาะ
ATier A, B
BTier A, B, C
CTier B, C, D
DTier C, D

ตัวกรอง

  • ช่วงเวลา — 1 เดือน / 3 เดือน / 6 เดือน
  • Status Filter — Completed only หรือทั้งหมด
  • Active Promoters Only — แสดงเฉพาะคน active
  • Sort by — ชื่อ, ยอดขาย, เฉลี่ย/วัน, PI, เกรด

🤖 Auto Assign

วิธีใช้

  1. เลือก ช่วงวันที่ ที่ต้องการจัดกะ
  2. พิมพ์ เงื่อนไขพิเศษ (ถ้ามี) เช่น "Ali ต้องอยู่ VDM ทุกวันจันทร์" หรือ "ร้าน JME ต้องมีคนอย่างน้อย 2 คน"
  3. กด Generate — AI จะวิเคราะห์เงื่อนไขและ Optimizer จะจัดกะ
  4. ดู Preview ตารางกะที่จัดให้
  5. ปรับแก้ได้ก่อน แล้วกด Apply Shifts เพื่อบันทึก

Optimizer ทำอะไร

UAE: จัดกะรายวัน — หมุนเวียนร้านทุกวัน โดยอิง Performance + Tier + Preferences

Qatar: จัดกะแบบ Block (~2 สัปดาห์อยู่ร้านเดียว) + เวียนคนไปตรวจร้านที่ performance ต่ำ สัปดาห์ละ 1 ครั้ง (วัน weekday เท่านั้น)

ข้อมูลที่ใช้คำนวณ

  • Store Tier (A/B/C/D) จากหน้า Sales Performance
  • Promoter Grade จากหน้า Sales Performance
  • Store Preferences จากหน้า PC Setting
  • Promoter Conflicts จากหน้า PC Setting
  • ยอดขายย้อนหลัง (Performance Matrix)
  • วันหยุดของแต่ละ Promoter

⏰ Attendance

ภาพรวม

หน้านี้แสดงข้อมูล check-in/check-out จาก LINE พร้อมเทียบกับกะที่จัดไว้

ด้านบนมี Summary Cards 5 ช่อง:

  • Total Records — จำนวนรายการทั้งหมด
  • Today — จำนวนรายการวันนี้
  • Alerts — จำนวนรายการที่มีปัญหา
  • Late In — จำนวนคนเข้างานสาย
  • Early Out — จำนวนคนออกก่อนเวลา

ประเภทการแจ้งเตือน

Alertเงื่อนไข
Late InCheck-in ช้ากว่าเวลาเริ่มกะมากกว่า 15 นาที
Early OutCheck-out ก่อนเวลาจบกะมากกว่า 15 นาที
No Check-inมีแต่ check-out ไม่มี check-in
No Check-outมี check-in แต่ไม่มี check-out (วันผ่านไปแล้ว)
No Shiftไม่มีกะที่จัดไว้ในวันนั้น
Unmatchedไม่สามารถจับคู่ชื่อกับ Promoter ในระบบได้
ระบบเปรียบเทียบเวลาจริงกับ Shift Time Range ที่จัดไว้ หรือเวลาเปิด-ปิดร้าน

ตัวกรอง

  • Search — ค้นหาชื่อ, ร้าน, วันที่
  • Date Range — กรองช่วงวันที่
  • Alerts Only — แสดงเฉพาะรายการที่มีปัญหา

🗄️ Database

แสดงข้อมูล Shift ทั้งหมดในรูปแบบตาราง 1 แถว = 1 คน × 1 วัน

  • ค้นหา — พิมพ์ชื่อ Promoter, วันที่, รหัสร้าน
  • แบ่งหน้า — 50 แถวต่อหน้า
  • แสดง: วันที่, ชื่อ Promoter, ประเภทกะ, ชื่อร้าน, ช่วงเวลา, โน้ต

📤 Export ข้อมูล

กดปุ่ม Export ที่มุมบนขวาของหน้า Shift Table:

  1. เลือก ช่วงวันที่ ที่ต้องการ export
  2. เลือก Promoter ที่ต้องการ (เลือกทั้งหมดหรือบางคน)
  3. เลือก รูปแบบ:
    • Image (PNG) — ภาพ screenshot ของตาราง
    • Text — ข้อความ plain text
    • CSV — ไฟล์ .csv สำหรับเปิดใน Excel

💬 LINE Attendance (บันทึกเวลาอัตโนมัติ)

วิธีทำงาน

เมื่อ Promoter ส่ง รูป screenshot check-in/check-out ใน LINE Group ระบบจะ:

  1. รับรูปจาก LINE Group ผ่าน Webhook
  2. ส่งรูปให้ Gemini AI อ่าน (OCR) ข้อมูลจากภาพ
  3. จับคู่ Promoter จากชื่อ/รหัสพนักงาน กับฐานข้อมูล
  4. จับคู่ร้าน จากรหัส/ชื่อร้านในภาพ
  5. บันทึก ลง Supabase ตาราง attendance อัตโนมัติ

รูปแบบที่รองรับ

Formatตัวอย่างข้อมูลที่ได้
CheckIn App Screenshot หน้าจอ app ที่มีชื่อ, รหัส, ร้าน, เวลา ชื่อ, รหัสพนักงาน, ร้าน, เวลา, วันที่
GPS Map Camera Selfie รูป selfie ที่มี GPS overlay เวลา, วันที่, พิกัด (จับคู่ Promoter จาก LINE user ID)

เช็คข้อมูลที่บันทึก

ดูใน Supabase SQL Editor:

SELECT promoter_name, store_code, date, check_in, check_out, status
FROM attendance ORDER BY created_at DESC LIMIT 20;
